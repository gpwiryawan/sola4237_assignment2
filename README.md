# SOLA4237 Assignment 2 – Home battery optimisation (Toowoomba, QLD)

Single site battery optimisation under flat, ToU and wholesale-passthrough tariffs,
with perfect foresight and 48 h rolling-horizon operation using a PV forecast and
AEMO pre-dispatch prices.

## Environment
Google Colab (Python x.y), packages in requirements.txt. Data in Google Drive folder "SOLA4237-A2".

## Data (not included in this repo)
- Course dataset: Data_QLD_Toowoomba - Warm Temperate_2022-2023_partial.csv (provided by SOLA4237)
- AEMO price & demand, QLD1, 2022–2023 (aemo.com.au aggregated data)
- AEMO pre-dispatch PREDISPATCHPRICE, Dec 2022 – Dec 2023 (NEMWEB MMSDM, PREDISP_ALL_DATA)
